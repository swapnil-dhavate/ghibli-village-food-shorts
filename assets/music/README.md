# Background music

Drop free, royalty-free, no-attribution-required instrumental tracks here with these exact
filenames (1-3 minutes each is plenty -- the pipeline loops/trims to fit, same as assets/sfx/):

```
calm.mp3
cozy.mp3
upbeat.mp3
curious.mp3
emotional.mp3
```

Instrumental only (no vocals/lyrics -- those clash with narration).

## Where to get them for free

- https://pixabay.com/music/ -- everything free for commercial use, no attribution required,
  no login needed.
- YouTube Studio Audio Library (studio.youtube.com -> Audio Library -> Music tab) -- filter
  for "Attribution not required" only, to keep things simple.

If a mood file is missing, the pipeline falls back gracefully (same pattern as missing SFX
tags) -- add them whenever you have them, nothing else needs to change.
